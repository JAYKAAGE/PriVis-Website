Continuous Active Directory Compliance

Built for IT administrators and security teams managing complex directories

Active Directory environments accumulate silent risk over years of role changes, contractor onboarding, and emergency privilege grants. PriVis continuously evaluates every identity, credential flag, and Group Policy setting against least-privilege baselines.

Continuous AD & Entra Sync

Synchronizes users, Organizational Units, nested security groups, and service accounts automatically without modifying production directory objects.

Credential Hygiene Alerts

Detects PasswordNeverExpires flags, reversible encryption, Kerberoastable SPNs, AS-REP Roasting exposure, and stale KRBTGT password rotation.

GPO & Setting Drift Detection

Alerts administrators when SMBv1 is enabled, LDAP signing is weakened, NTLMv1 fallback is permitted, or Domain Controller audit policies drift.

Contractor & Offboarding Audit

Flags active accounts past contract end dates, orphaned security group memberships on disabled users, and unapproved elevated privileges.

Blast-Radius Simulations

Model group membership changes before applying them in Active Directory to verify whether an identity gains unintended Tier-0 paths.

Audit-Ready Evidence & Scripts

Generates ready-to-review PowerShell remediation commands and SOC 2, ISO 27001, and NIST 800-53 compliance posture reports.

Zero-Write Architecture

            

              How PriVis Runs Locally & Syncs with Active Directory
            

            

              Run the PySide6 desktop application locally with launch.sh or launch.bat, or connect the read-only LDAPS collector to synchronize live Active Directory telemetry.
            

          

          
        


        
        

          

            
STEP 01 // LAUNCH DESKTOP APP

            
PySide6 6.12.0 & pandas 3.1.1

            

              Extract PriVis-Release-Bundle.zip and execute ./launch.sh (macOS/Linux) or launch.bat (Windows) to launch the native GUI.
            

          

          

            
STEP 02 // INGEST & EVALUATE

            
CSV Exports or Read-Only LDAPS

            

              Load exported Active Directory CSV tables via data_loader.py or poll your Domain Controller over LDAPS (port 636) without Domain Admin rights.
            

          

          

            
STEP 03 // REMEDIATE & SIMULATE

            
Verified PowerShell & What-If Tests

            

              Inspect evidence trails, test group changes in simulation_page.py, and apply prioritized solutions from solutions_page.py.
            

          

        


        
        

          

            

              
              Quickstart — PriVis Desktop & AD Sync Setup
            

            
          

          
# 1. Extract PriVis-Release-Bundle.zip and install dependencies
unzip PriVis-Release-Bundle.zip -d PriVis && cd PriVis
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt   # pandas==3.1.1, PySide6==6.12.0

# 2. Launch the PriVis Desktop Application
python app.py
